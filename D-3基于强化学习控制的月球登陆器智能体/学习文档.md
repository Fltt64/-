# 月球登陆器智能体 — real 环境二次开发学习记录

## 1. 环境设计

- **base**：已有，`LunarLander-v3`，8 维观测 + 4 离散动作。
- **real**：二次开发，在 base 上叠加三种真实扰动（`real_env.py`），并增加最终评分 `final_score = (0.2·fuel + 0.4·precision + 0.4·stability) × completion`。

| 扰动 | 参数 | 作用 |
|------|------|------|
| 传感器高斯噪声 | σ=0.10 | GPS/IMU 读数不准 |
| 控制延迟 | 8 帧 FIFO（≈160ms） | 推进器点火延迟，迫使预判 |
| 随机阵风 | 概率 18%，持续 8~32 帧 | 外部侧风扰动 |

## 2. 算法选择

沿用已有 **PPO**（Stable-Baselines3），本次不换算法，只升级网络结构与激活函数。

## 3. 训练参数（三阶段修改）

**阶段 1 — 调参（不改代码）**

| 参数 | 修改 | 原因 |
|------|------|------|
| 训练量 | 1M → 2M~5M | real 更难，需更多样本 |
| N_ENVS | 16 → 32 | 提高采样效率 |
| ENT_COEF | 0.01 → 0.03 | 噪声大，需更多探索 |
| LEARNING_RATE | → 1e-4 | 噪声下训练更稳定 |

**阶段 2 — 奖励函数（改 `conf.py` + `reward_process.py`）**

| 项 | 修改 |
|----|------|
| 燃料惩罚 | MAIN 0.30 → 1.0，SIDE 0.03 → 0.1 |
| 着陆奖励 | 按 \|x\| 位置给 100~300 连续奖励 |
| real_score | 把 final_score 混入 terminal 奖励 |

**阶段 3 — 网络结构（改 `conf.py` + `actor_critic.py`）**

| 项 | 修改 |
|----|------|
| 隐藏层 | [64,64] → [128,128]（或 [256,128,64]） |
| 激活函数 | Tanh → ReLU/ELU |

**课程学习（base → real 微调）**

- `algorithm_ppo.py`：`AlgorithmPPO` 新增 `init_model_path`，用 `PPO.load(path, env=env, device=device)` 加载权重后接当前环境。
- `train_workflow.py`：`workflow()` 新增 `init_model_path` 并透传。
- `train_base.py` / `train_real.py`：新增 `--init-model` 参数。

用法：先 `train_base.py` 收敛，再 `train_real.py --init-model logs/ppo/.../best_model.zip` 微调。

## 4. 训练曲线（评估均值回报）

| 实验 | 步数 | 最终均值回报 |
|------|------|-------------|
| base_7 | 1M | 257.1 |
| real_1 | 1M | 111.2 |
| real_3 | 2M | 104.1 |
| real_12 | 2M | 154.2 |
| real_13 | 2M | 220.9 |
| real_14 | 2M | **251.0**（max 422.7） |

real 环境均值从 111 逐步提升到 251，说明「调参 → 奖励改进 → 网络升级 + 课程学习」逐步有效。

## 5. 最终智能体表现分析

- 最优模型 `real_14` 均值回报 251.0，超过 200 通关线，课程学习迁移有效。
- 奖励改进让智能体从「能着陆」走向「省油、精准、平稳」。
- 仍存在最低 -322 的坠毁局，噪声/延迟下泛化未完全覆盖，可继续增大训练量或细化 real 难度分级。
